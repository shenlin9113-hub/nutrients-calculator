# 每日三大产能营养素计算工具

单用户命令行工具：按早/中/晚记录食物与克重，汇总蛋白质、脂肪、碳水与能量（千卡）。

能量公式：蛋白质×4 + 脂肪×9 + 碳水×4。

本版本不做生熟换算、烹饪损失或微量营养素。内置表中「米饭（蒸，熟）」「馒头（蒸，标准粉）」「面条（煮，熟）」的 `note` 为「熟重」，仅作标注。

## 运行

Python 3.10+。在本目录执行：

```text
python cli.py
```

`data/builtin_foods.json` 为内置食物库（只读）。`data/custom_foods.json` 为自定义食物（可写，初始为空数组）。

`nutrition.db` 在首次运行时自动创建，属于本地数据，不要提交到版本库。

## 主菜单

1. 记录某天饮食（每添加一条立即写入数据库）
2. 查看某天明细
3. 查看历史汇总
4. 添加自定义食物（每 100g 或按份换算）
5. 管理自定义食物
6. 把某天标记为无法记录
7. 删除操作（需输入 yes 确认）
8. 退出

## 测试

```text
pip install -r requirements.txt
python -m pytest tests
```

测试使用临时目录中的数据库与 JSON，不会改写本目录的 `nutrition.db`。
